# Feature Template

1. **Goal** — one sentence; who it's for; success criteria.
2. **Surface** — pages/components/routes touched.
3. **Data** — tables, columns, RLS, indexes.
4. **States** — loading, empty, error, success.
5. **Plan** — list files to create/modify before writing code.
6. **Tests** — unit + E2E to add.
7. **Done** — checks pass, mobile verified, no new Sentry errors.
